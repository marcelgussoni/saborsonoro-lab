# Sabor Sonoro Lab

Páginas especiais do Sabor Sonoro, publicadas em **lab.saborsonoro.com.br**.
O site principal (saborsonoro.com.br, WordPress) não é afetado por este repositório.

## Como funciona

- Cada ação fica numa pasta própria, com um `index.html` dentro.
  Exemplo: `cardapio-natal/index.html` → `lab.saborsonoro.com.br/cardapio-natal`
- Imagens e arquivos da ação ficam na mesma pasta (ex.: `cardapio-natal/img/`).
- Todo envio para a branch `main` publica automaticamente no Cloudflare Pages
  (projeto `saborsonoro-lab`, endereço técnico `saborsonoro-lab.pages.dev`).
- Nada aqui aparece no Google: o `robots.txt` bloqueia a indexação.

## Nomes de pasta

Minúsculas, sem acento, palavras separadas por hífen.
Exemplos: `cardapio-natal`, `orcamento-fotografia-2027`, `degustacao-vermutes`.
